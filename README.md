# gremlin

Small utilities from bunniesinc.

| Tool | Platform | What it does |
| --- | --- | --- |
| [gremlin](gremlin) | macOS | Menu bar app: `⌘⇧1` copies text from a screen selection, `⌘⇧2` copies a color as hex, and it unsticks Universal Control |
| [wamove](wamove) | macOS | Moves WhatsApp chats and media from Android to an iPhone that is already set up |

## Install

```sh
git clone https://github.com/alicin/gremlin.git
./gremlin/install.sh
```

`install.sh` builds and installs every tool that supports the current platform. Each tool also has its own `install.sh`.
